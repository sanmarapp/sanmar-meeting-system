# Sanmar Meeting System

Multi-tenant meeting room and site visit booking platform for Sanmar Properties Limited.

## Tech Stack

- **Backend**: NestJS + TypeScript + Prisma
- **Frontend**: React + TypeScript + Tailwind CSS + Vite
- **Database**: PostgreSQL + Redis
- **Deployment**: Railway
- **Notifications**: WhatsApp (Walinko) + Email (AWS SES)

## Features

- Office meeting room bookings with approval workflows
- Client site visit scheduling (Sales/CSD manages)
- Project site management with marketing suite configuration
- Smart notification system (WhatsApp + Email)
- Multi-location support (Tower One Chittagong, Tower Two Dhaka)
- Admin dashboard for system configuration
